# Part 1: Data Audit & Business Understanding

## Project Goal
This is Part 1 of my Capstone Project. The goal is to analyze the raw data for a D2C personal care brand to understand why customers are churning.

## Files in this Repository
1. eda_audit.ipynb: The Python code that loads the data and creates the charts.
2. data_quality_report.md: A report explaining the missing values we found (like missing Loyalty Tiers).
3. business_memo.md: A memo to the boss explaining that "Baby Care" and "Google Search" users are high risk.
4. requirements.txt: A list of tools needed to run the code.

## Key Findings
- Google Search users churn the most (50.43%).
- Baby Care is the riskiest product category (50.72%).
- Missing Loyalty Tiers: Over 1,000 customers have no loyalty tier, and they are very likely to leave.
